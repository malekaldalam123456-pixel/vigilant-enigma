EARN IT — الحزمة الكاملة
========================

المحتويات:
- index.html: التطبيق كاملًا.
- manifest.webmanifest: إعدادات تثبيت التطبيق.
- sw.js: التخزين المؤقت والعمل دون اتصال بعد أول زيارة.
- icon-192.png و icon-512.png: أيقونات التطبيق.

التشغيل:
1) فك ضغط EARN-IT-PWA.zip.
2) افتح المجلد في VS Code.
3) شغّل index.html باستخدام إضافة Live Server.
4) لتمكين التثبيت والعمل دون اتصال، افتح الموقع عبر HTTPS أو localhost ثم انتظر اكتمال التحميل الأول.
5) من قائمة المتصفح اختر Install app / تثبيت التطبيق.

مهم:
- بيانات التطبيق محفوظة محليًا في المتصفح وعلى نفس الجهاز.
- تسجيل الدخول تجريبي محلي وليس نظام حسابات آمنًا.
- لا توجد مزامنة سحابية أو مستخدمون حقيقيون متصلون.
- احتفظ بنسخة احتياطية من بياناتك من داخل التطبيق قبل حذف بيانات المتصفح.
